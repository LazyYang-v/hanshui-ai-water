# 功能清单与页面

## 功能清单

- [x] **M0 数据底座**：表结构（TimescaleDB）、水厂过程模型、场景注入、历史回填、实时推送
- [x] **M1 后端 API**：REST + WebSocket，FastAPI，文档见 http://localhost:8000/docs
- [x] **M1 简版大屏**：Vue 3 + ECharts，集控总览（厂站分布、实时指标、24 小时趋势、告警）、AI 助手抽屉（SSE 进度、可点引用、SQL 与结果表）、演示控制台
- [x] **M2 LLM 网关 + Text2SQL + 评测集**（见 [text2sql.md](text2sql.md)）
- [x] **M3 RAG 知识问答**：来源追溯、中文向量 + BM25、Flash 重排、引用校验、检索评测
- [x] **M3 Agent 连续对话**：LangGraph 编排查数与知识检索、单元格与原文引用校验、Redis 会话、SSE 进度、真实验收
- [x] **M4 告警工单 + 报告**：9 类规则、增量巡检与事件重放、带证据处置建议、确认后派单、可追溯日报/周报、离线评测与 Flash 验收
- [x] **M5 视觉巡检**：合成 + 公开数据训练 YOLO11n、ONNX CPU 推理服务、按摄像头合并告警、合成/真实分开评测、导出一致性与压测
- [x] **M6 曝气仿真（后端）**：固定曝气 / PI / 前馈 + PI / 负荷预测前馈 + PI 同扰动对照，校准与评测种子分开，对照接口供设定值滑块重算
- [x] **M6 交付**：智能曝气页面（设定值滑块实时重算）、前端容器化（nginx 同源代理 REST / WebSocket / SSE）
- [x] **前端业务页面**：厂站详情（工艺流程图叠加实时值、出水五项曲线、设备状态与曲线）、告警工单（筛选、指标曲线、AI 处置建议、草稿编辑与确认派单、工单看板）、视觉巡检（样例 / 上传推理、检测框叠加、模型卡）、报告中心（生成、Markdown 预览、Markdown / PDF 下载、校验过程）、新告警弹窗
- [x] **对话内派单**：AI 回答涉及具体厂站与时段时，服务端按本轮查询范围列出相关的未关闭告警（规则匹配，不由模型判断），可在对话里生成草稿、改步骤、确认派单，结果记回会话供追问
- [x] **管理员登录**：只设一个管理员账号；看页面不用登录，写入、调模型、注入场景、推理需要登录；会话存 Redis，用 HttpOnly Cookie 携带
- [ ] 演示录屏

## 页面

| 页面 | 路径 | 内容 |
| --- | --- | --- |
| 集控总览 | `/` | 天气、今日水量与药耗电耗、达标率、厂站分布（点击切换）、所选厂站实时指标（WebSocket，可跳转厂站详情）、近 24 小时趋势、告警列表（收到告警推送即刷新） |
| 智能曝气 | `/aeration` | 场景、DO 设定值滑块、随机种子、策略开关；DO / 风量与负荷 / 出水氨氮 / 电耗四图，指标卡标出相对固定曝气的变化 |
| 厂站详情 | `/plants/P01` | 7 座厂站切换；今日处理量、负荷率、吨水电耗、药耗、达标率；A2O / 氧化沟工艺流程图（SVG），各单元叠加 WebSocket 实时值，超预警标黄、超限标红，水泵、鼓风机、加药泵按运行 / 备用 / 告警着色，点击看曲线；出水五项近 24 小时 / 7 天曲线（限值线与预警线）；设备表与单台设备电流、振动、温度曲线；本厂未关闭告警 |
| 告警工单 | `/alarms` | 按状态 / 级别 / 类型 / 厂站筛选；详情含告警前后指标曲线（阈值线与告警区间）、关联告警、AI 处置建议（[n] 可点开证据，生成需付费调用约 5 千 tokens）；生成工单草稿后可改标题、增删改步骤（改过的步骤标为人工）、指派后确认派单；关闭告警需填写说明。`?tab=orders` 为工单看板：待处理 / 处理中 / 已关闭三列，可勾步骤、开始处理、填写处理结果关闭，数据已恢复时同步关闭告警 |
| 视觉巡检 | `/vision` | 选择厂站与摄像头、是否写入告警；点公开样例或上传图片推理；检测框按类别着色，低于告警阈值的画虚线；右侧列出置信度与阈值、各阶段耗时、产生的告警（可跳转）、模型卡（合成 / 真实验证集指标与局限）；样例图片显示署名与许可 |
| 报告中心 | `/reports` | 选择日报 / 周报与日期生成（付费，约 1 万 tokens；日期默认演示时钟当天，截至此刻）；列表标出模型叙述或模板叙述；Markdown 预览（经 DOMPurify 消毒），可下载 Markdown 或 PDF；可展开每次尝试的校验问题和全部统计事实 |
| 演示控制 | `/demo` | 演示时钟倍速、五类场景注入（可选厂站）、进行中场景列表与结束 |
| AI 助手 | 顶栏按钮 | 连续对话；逐步显示规划与工具调用；回答中的 [n] 可点开对应单元格或知识原文；查询结果能成图时自动画折线 / 柱状图（告警处置建议同样适用）；SQL 与结果表可展开；问到具体厂站与时段时列出相关未关闭告警，可就地生成草稿并确认派单 |
| 告警弹窗 | 全局 | WebSocket 收到新告警或升级时右下角弹出（最多 3 条，10 秒消失，告警级闪烁），点击进入告警详情 |

**自动图表**（`frontend/src/lib/autochart.ts`）：按 SQL 结果的列结构用固定规则选图，不调用模型，同一结果总是画出同一张图，表格始终保留。有时间列画折线（乱序先排序，跨日才显示日期），"时间 + 一个分类 + 数值"的长表按分类拆线（最多 7 条），只有一个分类列且不重复时画柱状图；编号、计数类列不画，极值类列让位给均值类；同轴峰值相差 5 倍以内，第二个量级放右轴，再不同的省略；只有一条线且能匹配指标目录时画限值线。判断不了（如多个分类维度混在一起、时间重复）就不画；省略了哪些列写在图下说明里。

测试共 **615 项**，覆盖模拟器（含曝气控制器接口不改变原模型输出）、曝气对照的公平性与接口、REST/WS、网关重试/降级/限流/并发上限/熔断与完整计时、SQL 安全校验、Text2SQL 自修复、RAG 检索与引用校验、评测判分、Agent 并行/取消与会话/SSE、服务端统计语义，告警规则、扫描合并与重放、处置建议、工单流转、报告数字与关系校验，以及视觉巡检的前后处理、告警合并、上传限制、评测指标和真实模型冒烟。2026-11-08 M6 曝气仿真加入后全量执行为 `566 passed in 47.18s`；新增重排预算、缓存/取消/计费、规划协议和诊断评分负例，保留逐时因果基线、迟到/缺失/9 天未恢复及三种进水负荷的 API 回归。测试使用假模型，不调用付费 API。数据库集成测试会重建独立的 `shuiwu_test` 库，并生成确定性数据；Redis 用 fakeredis，不会干扰正在运行的模拟器。数据库没启动时，数据库集成测试会跳过。
