# 智能曝气三策略对照报告（M6）

> **仿真结果，仅用于说明方法。** 模型是项目模拟器里的简化氧平衡，不是 ASM2，也没有用真实厂数据校核。下面的节能百分比只是这个模型、这个固定风量规则下的结果，不能当作真实厂的节能比例，也不沿用《AI 水务全场景》PDF 中的 30.4%。

2026-11-08 生成，原始数据：`calibration.json`（整定网格与 Pareto 前沿）、`eval.json`（评测汇总）、`simulator/aeration_params.json`（整定参数）。

```bash
uv run python -m evals.aeration.run calibrate   # 约 130 秒：只用校准种子 1–5、旱天、设定值 2.0
uv run python -m evals.aeration.run evaluate    # 约 60 秒：评测种子 101–110 × 4 个场景
```

## 结论速览

1. **反馈控制和固定曝气比较时，电耗差几乎全由固定风量怎么定决定。** 固定风量按旱天高峰（PI 风量的 95% 分位）配时，PI 在旱天省电 29.4%（10 个种子范围 26.8%–31.5%）。把固定风量降到中位数，电耗与 PI 相当（−29.1%），但旱天有 28.6% 的时间 DO 偏低，出水氨氮最高 23 mg/L，超过 5 mg/L 共 2.4 小时。这里的"29%"体现的是同样不超标的前提下少曝了多少气，不是控制算法本身的贡献。和 PDF 中的 30.4% 接近只是巧合。
2. **在这个模型里，前馈（实测负荷）基本没有增益。** 和 PI 比，DO 误差差别在 ±0.01 mg/L 以内，电耗差别在 ±0.1% 以内。原因是模型里的耗氧速率随进水负荷即时变化，没有水力停留带来的滞后；日内负荷变化以小时计，PI 来得及跟上。
3. **加负荷预测（Holt-Winters）的前馈比实测前馈更差。** 整定选出的预测提前量是 0 分钟。单独检验预测精度：10–60 分钟提前量下，HW 的误差都高于"沿用当前测量值"。即使日内规律完全已知，60 分钟的误差也只从 9.7% 降到 8.1%。模拟器的进水有约 50 分钟相关时间、约 8% 幅度的不规则波动，它比可预测的日内规律更大。
4. **风机能力不够时，三种控制都无能为力。** 在"超能力冲击"场景，所需风量超过两台运行鼓风机的上限（1.7 倍设计风量），PI 有约 150 分钟顶在上限。各策略的氨氮超标时长都在 4 小时左右（固定曝气 5.3 小时），差别主要来自冲击前后的风量分配，不是控制算法。

## 1. 模型与测量

主厂 P01（南郑中心污水处理厂，5 万 m³/d，A2O，3 台鼓风机中 2 台运行），沿用 `simulator/model.py` 的简化模型：

- 好氧池 DO：dDO/dt = KLa·(DOsat − DO) − OUR，KLa ∝ 风量，OUR 随进水需氧负荷 Q·(0.4·COD + 4.57·NH₃-N) 与 MLSS 变化；
- 硝化按 Monod 简化，出水氨氮受 DO 和温度影响；
- 鼓风机电耗 ∝ 风量^1.3（变频风机在实际工作区间的近似）。

为避免控制器"开天眼"，加了测量与执行环节：

| 环节 | 设置 |
|---|---|
| DO 探头 | 一阶滞后 60 秒 + 0.04 mg/L 白噪声，控制器拿到的是上一步末的测量值 |
| 进水流量计 | 1% 白噪声 |
| COD / 氨氮分析仪 | 5% 白噪声，每 10 分钟出一个值（期间保持） |
| 执行机构 | 变频鼓风机 + 阀门，一阶滞后 3 分钟 |
| 步长 | 60 秒 |

`PlantModel` 新增可选的 `controller` 参数（`AerationController` 协议：`command(obs) -> 风量`）。不传时走原内置 PI，结果与改动前逐位一致：7 座厂 2 天（60 秒步长）加 2000 步 5 秒步长、含暴雨/冲击/风机故障场景的输出指纹相同，`tests/test_aeration.py::test_legacy_path_unchanged` 持续检查。

## 2. 策略

| 代号 | 策略 | 说明 |
|---|---|---|
| `fixed` | 固定曝气 | 风量固定为整定后 PI 在校准日风量的 95% 分位（1.307 倍设计风量），模拟"按高峰配风、不随负荷调整"的人工经验 |
| `pi` | PI 反馈 | u = 1 + Kp·e + Ki·∫e（设计风量倍数），条件积分抗饱和，积分项最多 ±1.5。不用微分项，因为测量噪声下 D 只放大噪声 |
| `ff_pi` | 前馈（实测负荷）+ PI | 前馈 = a + b·测得负荷，经一阶滤波后输出；PI 修正残差。前馈按氧传递推动力换算到不同设定值：同一负荷下风量 ∝ 1/(DOsat − 设定值) |
| `ff_hw_pi` | 前馈（负荷预测）+ PI | 同上，负荷改用 Holt-Winters 预测的 h 分钟后值（乘法季节、5 分钟一槽、周期 1 天、无趋势），对应 DESIGN 6.4 的策略 C |

DESIGN 6.4 写的是"PID"，实现用 PI，原因见上表。负荷预测用 Holt-Winters，没有用 LightGBM：4 天在线数据训练树模型没有意义，而 HW 可以在线更新。

## 3. 公平性设计

- **共同随机数：** 同一种子下，各策略的进水、浓度、测量噪声完全相同。测试检查了不同策略的进水与负荷序列逐点相等。差别只来自控制。
- **整定与评测分开：** 参数只在校准种子 1–5、旱天、设定值 2.0 上整定；评测用种子 101–110，另含暴雨、冲击两类没参与整定的场景。
- **每个策略单独整定，不沿用别人的参数：** 预测前馈 + PI 有自己的 Kp、Ki、α、提前量与滤波时间。
- **动作预算：** 只看 DO 误差，网格会选出最大增益（Kp=2、Ki=4.8，风量每小时累计变化 1.6 倍设计风量），把测量噪声放大到鼓风机和阀门上。所以整定规则是：在"风量每小时累计变化 ≤ 0.5 倍设计风量"的预算内，取 DO 平均绝对误差最小；同时报告完整的 Pareto 前沿。
- **预热：** 每次先运行 3 天（同一控制器，供 HW 学习日内规律、状态进入稳态），只评测第 4 天（2026-11-05）的 24 小时。

## 6. 节能比例取决于固定风量怎么定

"较固定"是相对值，基准一变，结论就变：

| 固定风量取 | 旱天较 PI 电耗 | 旱天 DO 偏低 % | 旱天氨氮超 5 mg/L h | 暴雨超 5 mg/L h |
|---|---|---|---|---|
| PI 风量 95% 分位（主对照） | +41.7% | 0.4 | 0 | 3.28 |
| 75% 分位 | +17.0% | 8.0 | 0.33 | 4.35 |
| 50% 分位 | +0.5% | 28.6 | 2.42 | 5.16 |

固定曝气想在旱天不超标，就要按高峰配风；这时多出的约 40% 电耗就是"不调"的代价。反过来，按平均负荷配风也能做到和 PI 一样省电，但要拿出水超标去换。所以对外说"智能曝气省电 X%"时，必须同时说明基准怎么定、出水约束是否满足。本报告的主对照选 95% 分位，因为这是唯一在旱天不超标的固定风量。

## 7. 负荷预测为什么没有用

整定时 HW 预测提前量的候选为 0、10、20 分钟，预算内最优的是 0 分钟，也就是不提前。为了分开回答"预测准不准"和"预测对控制有没有用"，单独检验了 h 分钟后真实负荷的平均绝对百分比误差（种子 101–110 均值）：

| 场景 | 提前量 | 沿用当前测量值 | Holt-Winters | 日内规律完全已知（上限） |
|---|---|---|---|---|
| 旱天 | 10 分钟 | 5.2% | 7.2% | 5.2% |
| 旱天 | 30 分钟 | 7.4% | 9.2% | 6.9% |
| 旱天 | 60 分钟 | 9.7% | 10.6% | 8.1% |
| 暴雨 | 60 分钟 | 12.0% | 12.3% | 9.6% |

"日内规律完全已知"是用模拟器真实的日变化曲线，把当前测量值按曲线比例外推，代表季节性预测能达到的上限。这张表说明了两件事：

- **可预测部分本来就少。** 模拟器的进水在日变化曲线上叠加 AR(1) 波动（φ=0.98/分钟，相关时间约 50 分钟，流量与浓度合计约 8%）。这部分波动在 10–60 分钟尺度上不可预测，但有持续性，所以"沿用当前值"已经接近上限。
- **HW 还要付估计误差。** 季节因子只能从 3 天带噪测量中学到，每个 5 分钟槽的因子本身带着前几天的随机波动。在 10–30 分钟提前量上，它比直接用当前值更差。

预测前馈要有用，需要以下条件之一：一是负荷到达生化池有明显输送滞后（管网、提升泵站、初沉池），预测能"抢"出这段时间；二是分析仪更慢（如 30 分钟以上的取样周期），预测能补上测量空档；三是有可预测的外部信息（降雨预报、上游泵站排程）。这些在当前模型里都没有。在真实厂上评估预测前馈，应先测量进水到好氧池的实际滞后，再决定是否值得做。

## 8. 设定值敏感性

旱天，种子 101–105：

| 设定值 mg/L | PI kWh | 前馈 + PI kWh | 前馈 + PI DO MAE |
|---|---|---|---|
| 1.5 | 4595 | 4594 | 0.061 |
| 2.0 | 5026 | 5025 | 0.063 |
| 2.5 | 5534 | 5534 | 0.064 |

设定值每升 0.5 mg/L，电耗约增加 9%–10%。在这个模型里，降低 DO 设定值（在硝化允许的范围内）比换控制算法更省电。前馈系数只在 2.0 上拟合，按氧传递推动力换算后，1.5 和 2.5 下的误差没有变差，说明换算成立。

## 9. 局限

- 氧平衡和硝化都是简化模型，没有 ASM2 的组分划分、反硝化与好氧区溶解氧的空间分布，单点 DO 代表整个好氧池；
- OUR 随进水即时变化，没有水力停留滞后。这是前馈和预测都没有优势的主要原因，真实厂会不同；
- 电耗只算鼓风机，没有计入风压随阀门开度的变化（真实系统中，按最不利支路调风压能再省一部分电，这里没有建模）；
- 每个场景 10 个种子；整定网格较粗，选中的 PI 正好压在动作预算边缘（0.499），换一个预算，选出的参数和误差都会变；
- 固定曝气基准是人为规则，见第 6 节。

## 10. 接口

`GET /api/aeration/options` 返回策略、场景、设定值范围与当前整定参数；`POST /api/aeration/simulate` 运行一次对照：

```bash
curl -X POST localhost:8000/api/aeration/simulate -H 'Content-Type: application/json' \
     -d '{"scenario":"storm","setpoint":2.0,"seed":101,"strategies":["fixed","pi","ff_pi","ff_hw_pi"]}'
```

返回各策略的指标（含 `kwh_vs_fixed_pct`）、评测日 5 分钟粒度的 DO / 风量 / 电耗 / 出水氨氮曲线，以及公共的负荷、流量曲线，并在 `notice` 字段写明"仿真结果，仅用于说明方法"。一次对照约 0.7 秒（M3 本机），放在线程里执行，同时最多 2 个。设定值按 0.1 取整后缓存 64 组，供前端拖动设定值滑块时实时重算。
